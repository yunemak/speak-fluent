## Revisions

- Pin `qwen3:4b-q4_K_M` rather than the moving `qwen3:4b` alias: real inference showed the alias now resolves to Qwen3 Thinking 2507, produces reasoning despite `think: false`, and exhausts the short reply budget. The explicit original Qwen3 4B tag preserves the planned switchable-thinking behavior and local architecture.
- Put session orchestration in the framework-independent `frontend/src/lib/conversation.js` controller, with `useConversation.js` as its React binding, so focused race checks exercise production ordering and cancellation rather than mirrored helper logic.
- Installed project-local Python 3.12 and Ollama under ignored `.tools/` because only system Python 3.14 and no Ollama were available. Selected compatible Vite 7.3.7 / React plugin 5.0.4 after the initial Vite 8 pairing failed peer-dependency resolution; the chosen React/Vite/CSS Modules stack is unchanged.
- Use an absolute same-origin URL for ONNX runtime assets: the real browser check showed Vite intercepted relative dynamic `.mjs` imports from `public/` and rejected them. Same-origin absolute paths serve the copied files unchanged and passed the real speech loop without CDN requests.
- Tightened feedback instructions with conservative examples after the first real-model check unnecessarily replaced “like” with “enjoy” in a clean sentence. The clean-sentence check now passes; human evaluation of corrections remains part of the early checkpoint.
- Filter decorative emojis/emoticons in shared AI reply/report text and defensively before Piper synthesis after the learner heard an emoji name aloud. Prompt instructions alone did not reliably enforce spoken-only output. More natural voice exploration is deferred at the learner's request.
- Supersede the shared-text emoji filter after the learner clarified their preference: preserve emojis in display/report/storage text and filter only Piper's derived speech input. Reply validation still rejects emoji-only answers. Updated PRD and spec to capture this explicit behavior.
- Try `small.en` instead of `base.en` after real microphone misrecognitions, keeping faster-whisper on CPU int8 and pinned local downloads. Synthetic timing is acceptable for a human comparison, but whether accuracy improves remains the next hands-on check.
- Refined displayed emojis to clear emotional reactions, with a conservative text filter alongside prompts after prompt-only enforcement failed a neutral example. Added confirmed-speech gating before interruption after the learner reported breathing/cough false triggers; rejected candidate sounds no longer alter playback or phase. Updated PRD/spec to reflect the learner's intent and documented the responsiveness tradeoff and pending human verification.
- Decoupled short farewell capture from playback interruption after stricter noise filtering could drop brief closing words. Kept the learner-validated 320 ms interruption threshold, transcribed shorter candidates only for whole closing intent, and added explicit end/stop commands that the original matcher omitted. Updated PRD/spec to make both supported endings explicit.
